# Synainesi

**AI within your rules.**

Synainesi is the controlled, model-independent AI workspace for regulated work.
Employees get the leading AI models, tools and governed agents on Windows and macOS.
Organisations decide which models, tools, data flows and agent actions are allowed,
and Synainesi Guard enforces those rules on every device before anything leaves it.

Synainesi follows an open-core model. Open components will be published here.
